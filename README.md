# VisemePal

面向儿童英语发音的数字人口型与舌位可视化纠错系统。

针对儿童英语学习中「发音错误难定位、纠错过程不直观、学习反馈不及时」的问题，VisemePal 将语音评测、音素级诊断、数字人口型演示、舌位可视化与大模型个性化推荐结合起来，形成完整的智能纠错闭环：

**标准示范 → 跟读练习 → 发音评测 → 错误诊断 → 数字人纠错 → 智能训练推荐**

产品形态是 **Android App**：儿童在手机上完成示范、跟读、看数字人和舌位纠错。评测、音素诊断、资源库与个性化推荐放在 **Python FastAPI** 后端，App 通过 HTTP 调用。

---

## 项目背景

传统英语发音教学依赖教师示范与学生模仿，反馈慢、个性化不足。现有口语 App（多邻国、流利说、百词斩等）多停留在分数或简短文字提示，儿童很难理解「错在哪个音、嘴和舌头该怎么动」。

VisemePal 把评测从单词级推进到音素级，再用数字人口型与舌位动画把抽象发音动作变成看得见的纠错过程。

---

## 核心功能

| 模块 | 说明 |
| --- | --- |
| 发音资源库 | 整理儿童高频易错元音、辅音及易混淆音素，建立音素 ↔ 口型 ↔ 舌位 ↔ 发音规则映射 |
| 标准示范 | 播放目标单词 / 句子的标准发音 |
| 跟读采集 | Android 端录音，上传音频到后端评测 |
| 发音评测 | 接入语音评测服务，给出准确度分数与质量分析 |
| 音素级诊断 | 定位具体错误音素，生成针对性纠错提示 |
| 数字人口型 | 按错误音素驱动数字人口型动画，演示正确发音过程 |
| 舌位可视化 | 展示对应舌位示意图 / 发音器官动画 |
| 学习记录 | 保存练习历史、错误分布与进度 |
| 个性化推荐 | 基于历史数据与大模型，生成跟读材料、纠音建议与阶段训练计划 |

---

## 创新点

1. **音素级诊断**：从单词分数细化到具体错误音素，提高纠错针对性。
2. **数字人纠错**：评测结果直接驱动口型动作，动态展示正确发音。
3. **发音器官可视化**：建立音素、口型、舌位对应关系，降低儿童理解成本。
4. **大模型个性化推荐**：结合错误分布与学习进度，自动规划训练路径。

## 技术栈

Android 是面向儿童的主入口；Python 后端承接评测、诊断、资源与推荐，密钥与模型调用不进 App。

### Android 客户端（核心）

| 选型 | 用途 |
| --- | --- |
| Kotlin | 客户端主语言 |
| Jetpack Compose + Material3 | 儿童向界面与交互 |
| Android Studio | 开发与真机 / 模拟器调试 |
| MediaRecorder / AudioRecord | 跟读录音 |
| ExoPlayer / MediaPlayer | 标准发音播放 |
| Retrofit + OkHttp + Kotlin Serialization | 调用 FastAPI（课程、评测、可视化、推荐、记录） |
| Lottie / 自定义动画 | 数字人口型与舌位演示 |

### Python 后端

| 选型 | 用途 |
| --- | --- |
| Python 3.9+（推荐 3.11+） | 服务端语言 |
| FastAPI + Uvicorn | HTTP API：课程、录音上传、评测、可视化资源、推荐、学习记录 |
| Pydantic v2 | 请求 / 响应模型 |
| SQLAlchemy 2 + Alembic | 用户、练习记录、音素资源、推荐计划 |
| SQLite（开发）/ PostgreSQL（部署） | 持久化学习数据 |
| pydub、soundfile | 录音转码、切片、评测前预处理 |
| 讯飞 ISE | 发音评分与音素级结果 |
| DeepSeek V4.1 Flash（OpenAI 兼容） | 个性化训练内容与纠音建议 |
| pytest | 接口与诊断逻辑测试 |

讯飞评测与大模型密钥只放在后端环境变量中，不写入仓库或 App。

## 学习闭环

1. **示范**：从发音资源库取出目标词句，播放标准音频，并预览对应口型 / 舌位。
2. **跟读**：儿童在 App 内录音并上传。
3. **评测**：调用 ISE，得到总分、完整度、流畅度及音素序列。
4. **诊断**：将评测结果对齐到音素资源库，标出错误 / 易混音素，生成儿童可读提示。
5. **纠错**：按错误音素拉取口型与舌位动画，数字人演示正确动作。
6. **推荐**：汇总历史错误分布与进度，由大模型生成下一组练习与复习计划。

## 快速开始

> 后端可直接启动；Android 工程用 Android Studio 打开 `android/` 目录。

**1. 启动后端**

```bash
cd backend
python3.12 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -e ".[dev]"

cp .env.example .env               # 填写 ISE / LLM 密钥
alembic upgrade head
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

接口文档：`http://127.0.0.1:8000/docs`。  
开发控制台：`http://127.0.0.1:8000`（浏览器里跟读、评测、看口型舌位、记录和推荐）。

模拟器访问后端用 `http://10.0.2.2:8000`，真机用电脑局域网 IP。

**2. 启动 Android 客户端**

用 Android Studio 打开 `android/`，配置后端 Base URL 后运行到模拟器或真机。

主要后端环境变量：

| 变量 | 说明 |
| --- | --- |
| `DATABASE_URL` | 数据库连接串 |
| `ISE_APP_ID` / `ISE_API_KEY` / `ISE_API_SECRET` | 讯飞智能评测 |
| `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL` | 个性化推荐。默认 DeepSeek V4.1 Flash：`https://api.deepseek.com` + `deepseek-flash` |
